Pricing & GST
💰 Withdrawal / Conversion Settings
₹ per point  →  e.g. 100 pts = ₹10
Default: ₹0.10 per point (100 pts = ₹10)
Users need at least this many points to request withdrawal

🖼️ Banner Pricing — Per Day

Merchant selects any number of days + start date. Total = days × rate + GST

e.g. 30 days × ₹15 = ₹450 base
🎁 Product Pricing — Per Day

Merchant selects number of days + start date. Total = days × rate + GST

e.g. 45 days × ₹10 = ₹450 base
